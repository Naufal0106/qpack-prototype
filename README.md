# QPack Prototype — Full Frontend

Prototype frontend-only untuk presentasi/lomba KBMK.

## Halaman
- Public: Welcome, Login Role, Register Merchant, Register Konsumen
- Merchant: Dashboard, Produk, Checkout, Status Order, ESG, AI Report, Akun
- Konsumen: Dashboard, Scan QR, Hasil Scan, Reward & Impact, Akun

## Teknologi
- HTML5
- CSS3 responsive
- Vanilla JavaScript
- Asset SVG/PNG yang disediakan
- Tidak membutuhkan backend/database

## Jalankan
Buka folder dengan VS Code + Live Server, lalu buka `index.html`.

Login role Merchant mengarah ke Merchant Dashboard.
Login role Konsumen dapat diarahkan manual ke Consumer Dashboard jika diperlukan.
